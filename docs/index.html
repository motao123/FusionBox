核心特性

轻量、实用、可靠 —— 每一步都可回滚，拼错命令不会被关进菜单。

Bash 主程序；备份与受管应用使用 Python 3 标准库
支持 Debian / Ubuntu / CentOS / Fedora / Alpine
amd64 + arm64 双架构
中英双语界面，菜单 + CLI 双模式
自动检测系统环境与依赖
完整操作日志记录
内置一键更新
MIT 协议开源
未知命令给出明确报错与退出码，不静默进菜单
配置文件只声明真实生效的键
颜色与变量不进语言包，翻译可自由调整语序
隐私开关：匿名统计可一键关闭
