一条命令，接管整台服务器

FusionBox 将代理部署、系统调优、网络诊断、站点建设、容器应用与多机运维整合为单一入口。安装后即获得 9 个功能模块，所有配置变更均可回滚，界面支持中英双语。

$ bash <(curl -fsSL https://raw.githubusercontent.com/motao123/FusionBox/main/install.sh)

SCENARIOS

六类典型使用场景

每类场景列出最常用的三项操作，命令均可直接执行——已与 src/modules/ 中的分发表逐条核对。

代理服务部署

代理节点搭建与协议切换 · 4 种内核 · 15 种协议

$fusionbox proxy install# 内核安装：Xray / v2ray / sing-box / Clash.Meta
$fusionbox proxy add# 节点配置：VLESS / VMess / Trojan / Hysteria2 / TUIC
$fusionbox proxy sb# sing-box 管理入口

站点部署与证书管理

博客、落地页与内部系统 · 17 个应用 · 证书自动续期

$fusionbox web# LNMP 环境部署
$fusionbox web deploy# 应用安装：WordPress / Halo / Discuz / Memos
$fusionbox web ssl# 证书签发与自动续期，失败自动回滚

服务器性能与线路评测

选型评估与验收 · 单次运行输出完整报告

$fusionbox network bench# 集成 YABS / Bench 评测矩阵
$fusionbox network trace# 三网回程路由追踪
$fusionbox network streaming# 流媒体解锁检测

面板与容器工具

图形化管理与常用服务 · 75 款软件 / 10 个分类

$fusionbox panels docker# Docker 完整管理，含端口占用处理
$fusionbox market# 按分类安装 75 款软件
$fusionbox panels compose-backup# 已有 compose 项目的备份与迁移

受管应用生命周期

部署、备份、卸载、重装全程可管 · 10 个内建模板

$fusionbox market managed catalog# 查询清单：资源限额、端口、磁盘要求
$fusionbox market managed status <应用># 健康检查与运行状态
$fusionbox market managed reinstall <应用> --confirm --reuse-data# 复用数据卷重装

多服务器批量运维

面向集群与长期运维 · 批量执行 / 同步 / 编排

$fusionbox cluster add# 纳管主机，基于密钥认证
$fusionbox cluster exec# 全集群批量执行
$k# 集群快捷命令
RELIABILITY

配置变更全程可回滚

自动化脚本的主要风险不在于安装失败，而在于变更中断后系统处于不可用状态，且难以定位到具体步骤。FusionBox 对每一次配置写入执行完整流程：

暂存→ 备份→ 写入→ 校验→ 失败自动回滚 系统不会停留在中间状态
✓

未知命令处理

未知子命令返回明确提示与退出码 2；交互菜单仅在终端会话中启用，脚本与 CI 环境不会阻塞等待输入。

✓

受管应用采用声明式定义

镜像以 digest 固定，服务默认仅监听 localhost，配置内存 / CPU / PID 限额与健康检查，部署前执行磁盘容量预检；卸载保留数据卷，重装可复用。

✓

配置项全部可追溯

config.yaml 中每个键均对应实际读取位置，不存在声明后不生效的开关。

FEATURES

九大功能模块

每个模块均提供逐命令帮助说明 fusionbox help <模块>，并附带一项针对当前主机的只读状态探测。

代理管理

fusionbox proxy

支持 Xray / v2ray / sing-box / Clash.Meta 4 种内核，覆盖 VLESS、VMess、Trojan、Hysteria2、TUIC、Shadowsocks、SOCKS5 共 15 种协议。提供内核安装、节点增删、订阅配置、运行状态查询与内核切换。

系统管理

fusionbox system

BBR 与内核参数调优、性能基准测试、SSH 密钥与认证策略、防火墙规则、磁盘管理与回收站、swap 配置、定时任务、故障救援模式，以及 29 个城市时区预设（支持自定义 IANA 名称）。

网络工具

fusionbox network

IP 与归属查询、流媒体解锁检测、带宽测速、DNS 方案对比、路由追踪与 MTR、端口连通性检测，并提供集成式 VPS 性能评测矩阵，单次运行输出完整报告。

网站部署

fusionbox web

LNMP / LAMP 环境部署、站点与 Nginx 虚拟主机管理、反向代理与四层转发、17 个应用一键安装（WordPress、Halo、Discuz、Nextcloud、Memos、Vaultwarden 等）、SSL 证书签发与自动续期、站点数据备份与恢复。

面板与工具

fusionbox panels

Docker 完整管理（镜像、容器、卷与端口占用处理）、镜像加速源配置、宝塔面板、FRP 内网穿透、Aria2 下载、Rclone 网盘挂载、哪吒监控，以及既有 compose 项目的备份与迁移。

应用市场

fusionbox market

75 款软件分 10 个分类安装；managed 子命令提供受管生命周期，包含 10 个内建模板与 4 个纯 JSON 声明式条目，覆盖安装、更新、备份、卸载与重装。

WARP 管理

fusionbox warp

Cloudflare WARP Proxy 模式与 SOCKS5 出站，支持一条命令切换出口链路，并与解锁检测联动，用于评估当前线路质量。

后台工作区

fusionbox workspace

Screen / Tmux 会话统一管理，支持新建、接管、分离与日志回放。SSH 连接中断后任务持续运行，重新登录即可恢复现场。

集群控制

fusionbox cluster

多服务器批量执行、文件同步、归档与任务编排，支持游戏服务端部署、免密信任管理与 k 快捷命令。
