# 匿名统计与隐私

FusionBox 的匿名统计为可选功能，默认关闭。首次交互安装会询问一次，默认答案为否；非交互安装保持关闭。用户可以随时运行 `fusionbox privacy status|on|off|reset-id` 查看、启用、停用或轮换随机安装标识。第一阶段后端只接受安装、更新、卸载和心跳事件，用于了解版本采用情况及活跃安装量；不用于广告、跨站追踪或用户画像。

> 统计 Worker 已部署，公开汇总地址为 `https://fusionbox-telemetry.gdindex-demo.workers.dev/v1/public/summary`，事件接收地址为 `https://fusionbox-telemetry.gdindex-demo.workers.dev/v1/event`。匿名统计仍默认关闭，只有用户明确开启后才会发送。

## 处理的字段

事件包含协议版本、事件类型、随机生成的 128 位安装标识、FusionBox 版本、操作系统类别和 CPU 架构。服务端另用来源 IP 做短期限流，但不会保存完整 IP。

安装标识在写入或查询数据库前，使用仅保存在 Cloudflare Worker Secret 中的密钥做 HMAC-SHA-256。来源 IP 同样先做带域分隔的 HMAC，只进入短期限流记录。数据库不保存原始安装标识、完整 IP、User-Agent、命令参数、主机名、用户名、文件路径或其他自由文本。

## 保存与公开

首页“累计装机”读取 `installations_total`：服务上线后，主动同意统计并成功上报任一允许事件的随机安装标识去重总数。同一标识重复安装、更新或心跳不会增加；重置标识或删除本地配置可能再次计入。它不是物理服务器数或所有历史安装总量，不以 GitHub 下载量补足。关闭统计、离线或上报失败的安装不计入；公网汇总缓存五分钟。

统计事件按 UTC 日期、事件、版本、系统和架构聚合，不保存逐条原始事件。安装记录只保留 HMAC 后的标识以及首次、最后出现日期，用于计算累计和 30 日活跃安装量。限流记录在过期后通过请求触发的清理删除，正常保留不超过约两小时；若长期没有新请求，过期行可能延迟到下次清理，但不会再参与限流。

按日聚合数据和安装首次/最后出现日期在第一阶段长期保留，以支持历史趋势；运营方应至少每年复核必要性，并可通过删除 D1 数据库完成整体清除。公开接口只提供累计安装量、近 30 日活跃安装量及近 30 日事件总数，不公开单个安装或细分组合。

HMAC 标识属于假名化数据，不应视为不可逆匿名数据：持有服务端密钥的一方可能对已知候选值进行验证。密钥不得写入仓库、日志或客户端，并应通过 `wrangler secret` 管理。轮换密钥会使既有安装被视为新的安装。

## 关闭与删除

运行 `fusionbox privacy off` 会立即停止后续发送；运行 `reset-id` 会轮换本地随机标识。停用不会发送“关闭”事件，也不会自动删除已聚合且无法再关联到客户端明文标识的历史计数。统计服务由 FusionBox 项目维护，技术联系人和删除请求渠道以仓库公开 issue 为准。
