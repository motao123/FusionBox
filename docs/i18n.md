# 语言与本地化（i18n）

FusionBox 维护**两套地位对等的完整语言包**，界面语言可随时切换：

```bash
fusionbox lang            # 查看当前语言（非 root 可用）
fusionbox lang en         # 切到英文（写入 ~/.config/fusionbox/config.yaml 的 general.lang）
fusionbox lang zh_CN      # 切回中文
fusionbox lang auto       # 跟随系统 LANG
```

`auto` 的判定规则：**显式英文 locale（`en*`）用英文，其余一律中文**——服务器上常见
`C.UTF-8`（Ubuntu 云镜像默认）与未设置 `LANG` 的情况，不能因此把中文用户界面变成英文。
要英文请显式指定：`fusionbox lang en`，或单次覆盖 `FUSION_LANG=en fusionbox help`
（配置文件的值优先级高于环境变量）。

## 结构

| 文件 | 作用 |
|---|---|
| `src/i18n/zh_CN.sh` | 中文语言包（键值对，`MSG_*` / `MOD_*` 命名） |
| `src/i18n/en.sh` | 英文语言包（与中文包**键集合完全一致**） |
| `src/lib/i18n.sh` | 语言核心：加载两个包、按当前语言取值、缺失登记 |
| `scripts/i18n_extract.py` | 抽取器：把硬编码文案改写成键式调用并产出键表 |
| `scripts/i18n_audit.py` | 审计：键/占位符一致性、英文包纯净度、覆盖进度、内置表漂移 |
| `tests/test_i18n.py` | 契约测试（上一行各项 + 取值行为 + `lang` 命令接线） |

## 取值接口

```bash
msg      "$(L MSG_WEB_0142)"                  # 无参数：取原文
msg_err  "$(L MSG_WEB_0143 "$domain")"        # 带参数：按 printf 模板插值
printf '%s\n' "$(L MSG_COMMON_0008)"          # 需要格式串的调用点保留 printf
```

规则：

- **颜色不进语言包**。`msg "${F_GREEN}文本${F_RESET}"` 写成 `msg "$(L KEY "${F_GREEN}" "${F_RESET}")"`，
  模板里用 `%s` 占位，翻译时可自由调整语序。
- **模板里的字面 `%` 写成 `%%`**（只有带参数的键需要），否则 `printf` 会把它当格式符。
- 语言包缺键时**回退到另一语言**（绝不会把裸键名打到用户脸上），并登记到 `_I18N_MISSES`
  供测试与审计使用。
- 变量一律作为参数传入，**不允许出现在模板里**（抽取器有两条自检：变量数量必须与参数数量一致、
  模板不得残留 `$`；不满足就拒绝改写并交人工）。

## 抽取器用法

```bash
python3 scripts/i18n_extract.py --report                  # 全仓：各文件待抽取量
python3 scripts/i18n_extract.py --dry-run src/modules/system.sh
python3 scripts/i18n_extract.py --apply --json /tmp/keys.json src/modules/system.sh
```

抽取器**只改写它能完全看懂的形态**（`msg/msg_*/echo/printf` + 纯中文字面量 + 简单变量），
含 `$(...)`、`${x:-...}`、`${x:+...}` 的行会打印为 `SKIP` 并保留原样，由人工改写。
改写后必须核对：

1. `bash -n` 全部脚本；
2. **中文输出与改动前逐字节一致**（这是零回归的硬证据）；
3. 英文输出不含中文；
4. `python3 scripts/i18n_audit.py --coverage` 未抽取计数下降（不允许上升）。

## 覆盖进度与棘轮

`--coverage` 会给出逐文件未抽取文案数。核心层（`fusion.sh`、`install.sh`、`src/init.sh`、
`src/lib/common.sh`）**必须为 0**，由 `run_checks.sh` 第 22 节强制；模块层按批次推进，
覆盖计数只增不减（棘轮）。

## 边界

- **第三方工具输出不翻译**（docker、certbot、apt 等的原始输出），只能如实透传。
- **品牌与专有名词不翻译**（FusionBox、Cloudflare WARP、BBR、sing-box、YABS 等）。
- 日志文件内容跟随界面语言（便于用户排查），但**机器可读的字段（退出码、JSON、配置键）不翻译**。
- 安装器在仓库文件解压前只能使用内置的早期文案表（`install.sh` 中的 `_IL_ZH/_IL_EN`），
  该表由语言包生成，`tests/test_i18n.py` 校验两者**不得漂移**。
